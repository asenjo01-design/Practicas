# Estructura de Imágenes

Coloca tus imágenes en las siguientes ubicaciones:

## Galería
- `/galeria/pepito.jpeg` - Imagen de Pepito
- `/galeria/yo.jpeg` - Tu imagen

## Productos (cada producto tiene 3 imágenes)

### Peluche Unicornio
- `/productos/unicornio-1.jpeg`
- `/productos/unicornio-2.jpeg`
- `/productos/unicornio-3.jpeg`

- JPG/JPEG
- PNG
- WebP
- GIF

Todos los archivos DEBEN tener extensión .jpeg (no .jpg)
